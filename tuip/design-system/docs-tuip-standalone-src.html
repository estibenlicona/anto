Qué es tuip

tuip (Tuya UI Platform) es el sistema de diseño de las aplicaciones internas de Tuya y, a la vez, la herramienta de línea de comandos que lo reparte. No se instala como librería: cada componente se copia dentro de tu repositorio, con su código fuente legible y sus estilos ya alineados a los fundamentos.

terminal
copiar
$ npx tuip@latest init
$ npx tuip add button text-field data-table
Por qué copiar y no importar

Las apps internas de TI viven años y se bifurcan. Una dependencia versionada obliga a esperar al equipo de diseño para cualquier ajuste; un archivo en tu repo lo puedes modificar hoy y seguir recibiendo avisos de cambios con tuip diff.

Tú controlas
El markup, los handlers, las clases extra y cualquier regla de negocio que metas dentro del componente.
El sistema controla
Los tokens: color, tipografía, espaciado, radios y sombras. Se actualizan solos y no se editan a mano.
Los tres módulos

Fundamentos define las decisiones. Iconografía provee las 72 piezas del set. Componentes las combina en piezas instalables. tuip es el puente entre los tres y tu repositorio.

Fase actual
Fase 2 en curso: 18 componentes documentados, 12 disponibles en el CLI. Data table y Alert siguen en beta hasta cerrar accesibilidad de teclado.
Requisitos

Node 20 o superior, React 18 y un bundler que resuelva alias de TypeScript. El CLI detecta Vite, Next.js y el monorepo de TI; para cualquier otro setup pregunta las rutas al inicializar.

No edites tokens a mano
tuya-tokens.css se sobrescribe en cada update. Si necesitas un valor que no existe, pídelo al equipo de diseño: probablemente le falta al sistema, no a tu app.
Convención de overrides

Para cambios locales que quieras conservar, envuelve el componente en lugar de editarlo. tuip update solo pisa archivos dentro de components/ui que no tengan modificaciones marcadas.

button-aprobar.tsx
copiar
import { Button } from "@/components/ui/button";
export function ButtonAprobar(props) {
return <Button variant="primary" icon="check" {...props} />;
}

Reglas de uso

Máximo tres tamaños por pantalla. El peso 600 marca jerarquía; nunca uses mayúsculas sostenidas por encima de 13px. El texto largo no pasa de 68 caracteres por línea.

Uso del rojo

El rojo de marca solo aparece en la acción primaria, el indicador de sección activa y el logotipo. Los errores usan danger (#8E0F18), más oscuro y sin competir con el botón principal.

Regla dura
Un solo elemento rojo compitiendo por la mirada en cada vista. Si hay dos, ninguno funciona.
Alias

Nombras la relación, no el número. Si mañana la densidad cambia, se recalibra el alias y toda la plataforma respira igual.

Si la acción navega a otra pantalla sin efecto de escritura, es un enlace. Si hay más de cinco acciones juntas, es un menú.
